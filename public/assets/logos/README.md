# College Logos

Drop the real college logo files here using these exact filenames:

- `svit-logo.png`
- `svica-logo.png`
- `svion-logo.png`
- `svit-coa-logo.png`

Until a file is present the site renders a neutral gray placeholder box
containing the college short code — no AI-generated or stock imagery is used.

Recommended: transparent PNG, at least 512px on the long edge, roughly square.
