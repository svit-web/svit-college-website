# Suggested Programme Content

General wording for each `/courses/<code>` page, ready to copy into admin.

**How to use:** go to `/admin/tables/courses`, open the row with the code shown, and paste each value into the matching field. Add Highlights and Outcomes one line at a time with **Add item**.

**About this text:** it is general on purpose. It makes no claims about placements, rankings, salaries or facilities that SVIT would need to prove. Rows marked **Confirm** should be checked against the current GTU, ACPC or council rules before publishing.
